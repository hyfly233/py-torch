# Carrot AI Infra 交互原型（V2）

## 1. 核心导航

`总览 / 模型 / 模型服务 / GPU 资源 / API Keys / 租户与配额 / 告警与审计`

## 2. 部署流程（主路径）

```text
模型服务 → 部署服务
  1 选择 RELEASED 模型版本
  2 选择 GPU Pool、GPU 数、副本、上下文和启动参数
  3 资源预检：可用 GPU、租户配额、模型显存、预计成本
  4 确认：服务名、租户、访问策略、幂等键
  5 受理页：校验/提交/启动/网关配置进度
  6 服务详情：Endpoint、API 示例、指标、事件、操作
```

关键规则：不可部署版本不可选；资源不足时说明“需要/可用/配额”；重复提交展示原服务；部署失败必须提供诊断和重试。

## 3. 服务详情页

```text
qwen-prod   [扩容] [重启] [回滚] [删除]
状态 Running | Endpoint | 租户 | 模型版本 | 副本 2/2 | GPU 4

[性能] [GPU] [日志] [事件] [配置] [API 示例]
QPS  TTFT  TPOT  Token/s  错误率  队列长度
```

点击异常指标时，按时间范围联动展示：请求样本（脱敏）→ Pod → GPU 节点 → Kubernetes 事件。删除确认必须显示将释放的 GPU 和影响的 API 路由。

## 4. 资源与租户页面

- GPU 资源页：Pool → 节点 → GPU 卡三级展开，展示总量/已用/可用/健康/显存
- 租户页：配额、已用、队列、服务数、Token 用量；管理员可调整配额并查看审计
- API Key 页：创建、授权模型、禁用、轮换；创建成功页提供一次性复制入口

## 5. 状态反馈

所有异步操作使用“受理成功 + 轮询/事件流”反馈；刷新页面从服务端恢复状态。禁止仅依赖前端本地状态或把 `Starting` 伪装成 `Running`。
