# Carrot AI Infra 交互原型

本文档使用低保真线框描述 MVP 页面和关键交互，不绑定具体前端框架。

## 8. 关键流程

```text
总览 → 部署服务 → 选择模型 → 配置 GPU → 配置服务
  → 部署中 → 服务详情 → API 调用/查看指标
  → 扩缩容或删除 → 资源释放
```

## 9. 交互规则

- 删除服务必须二次确认，并显示将释放的 GPU 数量
- 服务处于 Starting 时禁止重复创建同名服务
- Failed 状态必须展示“原因”和“重试”入口
- 扩缩容操作显示变更前后副本数和 GPU 数量
- API Key 只在创建成功页展示一次
- 页面刷新后从后端重新获取状态，不依赖浏览器本地状态
