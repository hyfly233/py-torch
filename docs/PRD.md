# Carrot AI Infra PRD

## 1. 产品概述

### 1.1 产品名称

Carrot AI Infra Platform

### 1.2 产品定位

面向企业研发和平台运维团队的 AI 推理服务平台。用户无需直接操作 GPU、Kubernetes 或 vLLM，只需选择模型和资源规格，即可完成模型部署、调用、监控和下线。

### 1.3 产品目标

- 将 GPU 资源转化为可直接消费的模型服务
- 提供统一的模型部署和 OpenAI 兼容调用入口
- 降低模型上线和运维门槛
- 统一展示 GPU、推理性能、服务状态和资源成本

## 2. 用户角色

| 角色 | 主要诉求 |
|---|---|
| 平台管理员 | 管理 GPU 节点、资源池、租户和系统配置 |
| AI 工程师 | 注册模型、部署模型、调试接口、查看指标 |
| 应用开发者 | 获取 API Key，调用统一模型接口 |
| 运维人员 | 关注服务健康、GPU 利用率、错误和告警 |

## 3. MVP 用户故事

### US-001：查看 GPU 资源

作为平台管理员，我希望查看集群 GPU 节点、型号、显存和使用率，以便判断当前是否有可用算力。

验收标准：

- 能查看节点总数、GPU 总数和可用 GPU 数
- 能按 GPU 型号、节点状态筛选
- 能看到 GPU 利用率、显存占用和健康状态

### US-002：注册模型

作为 AI 工程师，我希望登记模型名称、版本、权重地址和运行时参数，以便后续部署。

验收标准：

- 模型名称和版本唯一
- 权重地址、运行时和 GPU 需求必填
- 模型状态可区分注册、校验通过和不可部署

### US-003：部署模型服务

作为 AI 工程师，我希望选择模型版本、GPU 数量和副本数，创建一个在线模型服务。

验收标准：

- 创建前显示资源预估
- 创建后显示 Pending、Starting、Running、Failed 等状态
- 失败时显示可理解的诊断信息
- 服务成功后返回 API Endpoint

### US-004：调用模型

作为应用开发者，我希望使用 OpenAI 兼容 API 调用模型，不需要了解底层 Pod 地址。

验收标准：

- 支持 `/v1/models`
- 支持 `/v1/chat/completions`
- 支持流式响应
- 无效 API Key 返回明确错误

### US-005：查看服务指标

作为运维人员，我希望查看模型服务的延迟、吞吐、错误率和 GPU 使用情况，以便判断服务是否健康。

验收标准：

- 支持时间范围选择
- 至少展示请求数、错误率、TTFT、Token/s、GPU 利用率
- 指标可按模型和副本查看

### US-006：扩缩容和下线

作为 AI 工程师，我希望调整副本数或下线服务，以便应对流量变化并释放资源。

验收标准：

- 扩容操作显示进度
- 缩容不会误删其他服务
- 下线后 Kubernetes 资源和 GPU 配额均释放

## 4. 功能需求

### 4.1 总览 Dashboard

- 集群 GPU 总量、已用量、可用量
- 在线模型服务数量
- 服务异常数量
- 最近部署记录
- GPU 利用率趋势

### 4.2 模型管理

- 模型列表、搜索和筛选
- 模型详情和版本列表
- 注册、编辑和删除模型版本
- 记录权重地址、框架、运行时、GPU 需求和上下文长度

### 4.3 模型服务管理

- 创建模型服务
- 查看服务状态、Endpoint、副本和资源
- 查看 Pod/事件/错误诊断
- 扩缩容、重启和删除
- 复制服务配置

### 4.4 API Key 管理

- 创建、禁用和轮换 API Key
- 绑定租户和权限
- 查看最近调用时间
- Key 只在创建时明文展示一次

### 4.5 监控

- GPU 指标：利用率、显存、温度、功耗、健康状态
- 推理指标：QPS、TTFT、TPOT、Token/s、错误率
- 资源指标：副本、CPU、内存、队列长度
- 支持服务和时间范围筛选

## 5. 非功能需求

- 创建、删除和扩缩容接口必须幂等
- 控制面重启后能从 Kubernetes 恢复服务状态
- API 请求必须带 Request ID
- 模型权重地址、Secret 和 API Key 不得写入普通日志
- 首版支持单集群，架构预留多集群适配
- 页面核心操作在 3 秒内返回受理结果，异步操作显示进度

## 6. MVP 非目标

- 不实现模型训练
- 不实现多集群调度
- 不自研推理引擎
- 不实现复杂的自动扩缩容策略
- 不实现完整计费结算，仅预留用量和成本字段

## 7. 发布验收

完成以下流程即视为 MVP 达标：

```text
发现 GPU → 注册模型 → 创建 vLLM 服务 → 获取 Endpoint
→ OpenAI API 调用 → 查看 TTFT/GPU 指标 → 扩容 → 删除并释放资源
```
